# a1-mcp-server — установка и запуск

## Требования

- **Node.js >= 22.19** (проверено на v24).
- **npm** (идёт вместе с Node).
- Доступ по сети к серверу Платформы A1 (REST API).

## 1. Установка зависимостей

В каталоге проекта выполните:

```bash
npm install
```

Этого достаточно — версии зависимостей зафиксированы в `package-lock.json`.

> Если в архив был включён `node_modules`, этот шаг можно пропустить.

## 2. Настройка подключения к A1

Отредактируйте `.env` (или задайте переменные окружения напрямую):

```env
A1_BASE_URL=http://<хост>:<порт>
A1_USER=<логин>
A1_PASSWORD=<пароль>
A1_MODE=readwrite
A1_LOG_LEVEL=info
```

- `A1_MODE=readonly`  — только чтение (write-инструменты скрыты).
- `A1_MODE=readwrite` — полный доступ (создание/удаление/запись).

## 3. Сборка (если нужно собрать из исходников)

```bash
npm run build
```

Собранный JS уже лежит в `dist/`, поэтому `node dist/index.js` работает сразу
после `npm install` (пересборка нужна только при изменении `src/`).

## 4. Запуск

```bash
node dist/index.js
```

Для разработки с перезагрузкой:

```bash
npm run dev
```

## 5. Подключение к MCP-клиенту (Zed / Claude Code)

Добавьте MCP-сервер:

| Поле | Значение |
|---|---|
| Name | `a1` |
| Command | `node` |
| Arguments | `/путь/к/a1-mcp-server/dist/index.js` |
| Environment | `A1_BASE_URL`, `A1_USER`, `A1_PASSWORD`, `A1_MODE` |

После добавления **перезапустите клиент** — MCP-сервер стартует только при
его запуске.

## Диагностика

- **`A1_BASE_URL` не найден / 401** — проверьте адрес, логин, пароль.
- **self-signed сертификат** — задайте `A1_SSL_REJECT_UNAUTHORIZED=false`.
- **write-инструменты не видны** — убедитесь, что `A1_MODE=readwrite`.
